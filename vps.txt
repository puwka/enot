1) Скопируйте содержимое папки build на сервер, например в /var/www/enotmani

2) Пример конфига nginx:

server {
    listen 80;
    server_name example.com;
    root /var/www/enotmani;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}

3) Перезапустите nginx:

sudo nginx -t
sudo systemctl reload nginx

4) Для HTTPS — certbot или свой сертификат.


7. Проверка после выкладки

1) Откройте главную страницу сайта.
2) Проверьте каталоги: кредиты, карты.
3) Зайдите в админку: https://ваш-домен/admin/login

Если админка пишет про отсутствие ключей — проверьте .env
и пересоберите проект (npm run build).


8. Если что-то не работает

- белый экран после деплоя — проверьте, что nginx отдаёт index.html для всех путей
- админка не входит — проверьте grant_superadmin.sql и что миграции применились
- пустые продукты — проверьте, что миграции с seed выполнились
- после смены .env нужна новая сборка, старый build не подхватит переменные
